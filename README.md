# AI Evasion Pipeline — Turnitin 0% Validated

A six-stage systematic pipeline for reducing AI detection rates in academic prose. **Battle-tested on Turnitin: 72% → 0% AI score.**

```
Stage 1: Vocabulary Cleaning    → Reduce AI-signature word density by ~60%
Stage 2: Rhythm Reconstruction   → Maximize sentence-length variance
Stage 3: Transition Elimination  → Replace connectors with semantic chains
Stage 4: Uneven Hedging          → Calibrated (not uniform) academic caution
Stage 5: Perplexity Maximization → Lower-frequency, precise word choices
Stage 6: Imperfection Injection  → 2-4 natural human micro-quirks per 1000 words
```

## The Core Principle

**AI detectors measure statistical pattern uniformity, not individual word choices.** A single "AI pattern" is invisible. A thousand identical patterns form a detectable signal. The defense is random variation across all dimensions — vocabulary, syntax, register, rhythm.

## Validation

Developed by submitting the same paper to Turnitin across multiple versions:

| Version | AI Score |
|---------|----------|
| Initial draft | 72% |
| Final | 0% (<20% threshold) |

## Stage-by-Stage Examples

### Stage 1: Vocabulary Cleaning

```
❌ "This critical review contends that IMRaD retains irreplaceable value"
✅ "This review argues that IMRaD remains essential for training new writers"
```

### Stage 2: Rhythm Reconstruction

```
❌ [Every sentence ~22 words]
"For novice researchers, IMRaD provides a cognitive scaffold guiding
learners through the intellectual sequence..."

✅ [Short→medium→long rhythm]
"IMRaD can provide a thinking support for newcomers. The training it
offers in systematic argumentation will maintain its lead."
```

### Stage 3: Transition Elimination

```
❌ "The ensuing scholarly debate divides along pedagogical and
epistemological lines."
✅ "The above-mentioned study has been divided by teachers and philosophers."
```

### Stage 4: Uneven Hedging

```
❌ (uniformly strong) "IMRaD will endure as an irreplaceable cognitive scaffold"
✅ (softer) "IMRaD will still be needed as a thinking scaffold for new researchers"
```

### Stage 5: Perplexity Maximization

```
❌ "Code functions as a first-class research output alongside text"
✅ "Code is another type of research result in the ecosystem, just like text"
```

### Stage 6: Natural Imperfection Injection

The 0% version contains these human micro-quirks (2-4 per 1000 words):
- `took shape over the late nineteenth` [missing "century"]
- `which rarely seen in standard IMRaD papers` [missing "is"]
- `community collaboration sometimes instead of, anonymous review` [awkward word order]
- `back end talk function after publishing by GitHub now` [informal insertion]

## Quick Diagnostic

| Symptom | Focus on Stage |
|---------|---------------|
| Uniform ~22-word sentences | 2 |
| Predictable transitions everywhere | 3 |
| Every claim equally confident | 4 |
| Zero grammatical imperfections | 6 |
| Reads like a polished textbook | 5 + 6 |
| >8 em-dashes per 1000 words | Remove first |

## What NOT to Do

- ❌ Add intentional grammar errors (Turnitin detects error-injection)
- ❌ Replace every academic word (triggers unnatural simplification)
- ❌ Use AI paraphrasing tools to evade AI detection
- ❌ Make text incoherent (random noise ≠ natural variation)
- ❌ Keep >8 em-dashes per 1000 words
